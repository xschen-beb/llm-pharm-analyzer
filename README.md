# LLM Pharm Analyzer

Code and prompt templates used for the LLM-based literature retrieval and LLM-as-judge evaluation described in the associated analysis.

## Overview

This repository contains:

- PubMed literature retrieval using the NCBI E-utilities API.
- Prompt templates for biomedical answer generation and LLM-as-judge evaluation.
- Utilities for rendering judge prompts and validating judge outputs.

## Requirements

- Python >= 3.10
- Access credentials for the selected proprietary LLM API (if running API-based evaluation)

## PubMed Retrieval

PubMed retrieval is implemented through the NCBI E-utilities API.

The retrieval configuration follows:

- Database: `db=pubmed`
- Ranking: `sort=relevance`
- History mode: `usehistory=n`
- Fetch type: `rettype=abstract`
- Return format: `retmode=xml`

Default retrieval sizes:

- Command-line interface default: `max_results=10`
- Programmatic API default: `max_results=20`

Example:

```bash
python -m llm_as_judge.pubmed.deep_search "atherosclerosis SZ-A" --max-results 10
```

## LLM-as-Judge Evaluation

The judge module provides:

- Prompt rendering from templates.
- LLM-based reviewer-style scoring.
- JSON output validation.

The evaluation prompt uses:

- Additive reviewer rubric with scores in the range 0-5.
- Mechanism confidence scoring in the range 1-5 for final mechanism evaluation.

## Running Judge Evaluation

Render a judge prompt:

```bash
python -m llm_as_judge.judge_run \
  --candidate-file candidate.md \
  --render-only
```

Run with an OpenAI-compatible API:

```bash
export OPENAI_API_KEY=<your_api_key>
python -m llm_as_judge.judge_run --candidate-file candidate.md
```
